# bacterial-16srrna-visualizations
A beginner bioinformatics project involving multiple sequence alignment, sequence visualization, conservation analysis, and phylogenetic tree generation of bacterial 16S rRNA sequences.


# 🧬 Bacterial 16S rRNA Visualization and Phylogenetic Analysis

## 📌 Project Overview
This project focuses on the comparative analysis and visualization of bacterial 16S rRNA sequences using bioinformatics tools and R programming.

The workflow includes:
- Retrieval of bacterial 16S rRNA sequences from NCBI
- Multiple sequence alignment using Clustal Omega
- Sequence visualization using Jalview
- Conservation analysis and sequence logo generation in R
- Phylogenetic tree construction using R packages

---

## 🧪 Tools and Technologies Used

- NCBI
- Clustal Omega
- Jalview
- R / RStudio
- Biostrings
- msa
- ape
- seqLogo

---

## 🔬 Workflow

NCBI → FASTA Sequences → Multiple Sequence Alignment → Visualization → Sequence Logo → Phylogenetic Tree
